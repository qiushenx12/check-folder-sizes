# check-folder-sizes（文件夹大小查看器）

一个 Windows 桌面小工具（tkinter，纯标准库、零第三方依赖），用来排查磁盘空间被谁占掉：
左侧是类似资源管理器的目录树，右侧按需列出当前目录下各子项的大小，按大小降序排列；
另有「专项清理」分页，针对已知安全/可控的占用项做专项扫描和一键清理。

## 功能

### 磁盘分析（分页一）

- **目录树导航**：左侧懒加载目录树（双击/点「+」展开），顶栏可直接输入路径跳转；
  启动时列出所有盘符
- **分析**：多线程统计当前目录的直接子项大小，底部状态栏显示「合计」与数据来源
- **递归分析**：把整棵子树逐层统计入库，之后进入任意子目录都免重扫
- **结果缓存**：分析结果保存在 `folder_sizes.db`（sqlite），切走再切回立即回看，
  状态栏区分「本次扫描 / 缓存（时间）」；路径大小写不敏感
- **右键菜单**（左右两侧均支持）：复制名称 / 复制路径 / 打开文件夹（资源管理器）
- **界面记忆**：窗口位置大小、左右分隔条比例、上次浏览的目录、上次所在分页
  保存在 `ui_state.json`，下次启动自动恢复（按逻辑像素存储，不受 DPI 缩放影响）
- **其他**：DPI 感知（Windows 高缩放下文字清晰）、自绘可拖分隔条、右侧日志面板、
  扫描期间切换目录结果不丢失

### 专项清理（分页二）

- **专项扫描**：按内置规则识别已知安全/可控的占用项，逐条显示大小、目标数、
  风险等级和说明；双击规则可查看命中的具体路径清单。当前规则：
  VS Installer 更新残留（每次自更新解压一份副本，从不清理）、Temp 其他临时文件、
  Unity / 团结引擎 Hub 下载缓存、npm 缓存、程序崩溃转储（以上为「安全」）；
  pnpm 存储（仅 store 子目录）、Edge 网站离线缓存（以上为「注意」，不默认勾选）
- **汇总统计面板**：可清理总量（命中规则数/目标数）、已勾选量、磁盘剩余空间；
  清理后显示本次释放量（成功/跳过/失败计数）
- **一键清理**：勾选规则后一键执行，删除前弹确认框；过程可视——进度条 +
  当前动作 + 明细日志（✓ 已删 / ⊘ 跳过 / ✗ 失败），清理完自动重新扫描刷新数字
- **两种删除方式**：默认移入回收站（`SHFileOperation` + `FOF_ALLOWUNDO`，可恢复，
  超出回收站容量时报错而非静默硬删）；取消勾选则永久删除（锁定/占用文件自动跳过）
- **进程保护**：Edge 运行中时其缓存规则整条跳过并提示，避免清到一半撞上文件占用
- 勾选集合与回收站开关随 `ui_state.json` 记忆

## 运行

```powershell
python app.py
```

要求：Windows + Python 3（自带 tkinter 即可，无需安装任何依赖）。

## 测试

```powershell
python test_smoke.py
```

端到端冒烟测试：目录树展开、顶栏导航、分析/递归分析、右键菜单、sqlite 缓存回看、
界面状态持久化，以及专项清理分页（临时目录夹具下的规则命中、永久删除、进程占用跳过、
失败计数、回收站通道 mock），全部通过时输出 `OK`。
